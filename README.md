# Silly Linkify

Silly Linkify связывает настройки SillyTavern в понятные правила.

Вы задаёте состояние, которое нужно отследить, и список действий, которые должны сработать вместе с ним.

Например:

- в пресете включается тоггл, вместе с ним включается нужный регекс
- выбирается другая модель, вместе с ней переключается пресет
- открывается карточка персонажа, вместе с ней включаются регекс, Quick Reply и профиль подключения

Это удобно, когда одна настройка почти всегда требует ещё двух или трёх связанных действий.

## Как это выглядит

Каждый линк состоит из двух частей:

- `When`, условие
- `Then`, результат

Пример:

```text
When
Preset prompt toggle = enabled

Then
Regex script = enabled
```

Если состояние из `When` совпадает с текущим состоянием Таверны, Linkify применяет `Then`.

В одном линке можно собрать несколько условий и несколько результатов.

## Ваш первый линк (так волнительно)

Откройте:

`Extensions -> Silly Linkify`

Дальше:

1. Нажмите `New link`.
2. Введите название.
3. В `Add block` выберите `When`.
4. Добавьте нужное условие.
5. Переключитесь на `Then`.
6. Добавьте одно или несколько действий.

Линк начинает работать сразу после сохранения.

## Пример 1. Тоггл в пресете включает регекс

Задача:

в пресете есть тоггл `Use Figure Spaces`, и вместе с ним должен работать регекс с тем же смыслом.

```text
When
Preset prompt toggle = Use Figure Spaces enabled

Then
Regex script = Use Figure Spaces enabled
```

Теперь одно переключение держит пресет и регекс в одном состоянии.

## Пример 2. Модель выбирает нужный пресет

Задача:

для конкретной модели нужен свой пресет.

```text
When
Chat Completion model
Source = OpenRouter
Model = google/gemini-...

Then
Active preset = Gemini-Preset
```

При смене модели пресет будет подхватываться автоматически.

## Пример 3. Персонаж включает свой набор

Задача:

у карточки есть собственная рабочая конфигурация.

```text
When
Selected character = Vivian Banshee

Then
Connection profile = Local RP
Regex script = enabled
Quick Reply global set = enabled
```

Так можно собирать отдельные профили поведения для разных персонажей.

## Пример 4. Пресет переключает персонажа

```text
When
Active preset = Character Setup

Then
Selected character = Vivian Banshee
```

Этот вариант полезен, когда пресет и карточка используются парой.

## Что можно связывать

### Пресет

- активный пресет
- prompt тогглы внутри пресета

Подходит для правил вроде:

- пресет включает регекс
- тоггл внутри пресета включает другой тоггл или Quick Reply

### Регекс

- регекс пресет
- конкретный регекс

Подходит для:

- включения обработки под модель
- включения регекса под персонажа
- синхронизации с пресет тогглами

### Character / Chat

- выбранный персонаж
- текущий chat
- выбранная группа

В выборе персонажа есть:

- мини-аватарки
- автор карточки, если он указан
- поиск по имени и автору

### API / Model

- Main API
- Chat Completion source
- Chat Completion model
- Connection profile

Для `Chat Completion model` сначала выбирается source, затем модель для этого source.

### Quick Reply

- global set
- chat set

Подходит для персонажей, пресетов и сценариев с быстрыми командами.

### Custom

- DOM control
- Extension settings path
- Context path
- Slash command

Это вариант для редких случаев и сторонних расширений.

## Auto inverse

`Auto inverse` возвращает простые переключаемые результаты обратно, когда линк перестаёт совпадать.

Пример:

```text
When
Active preset = Gemini-Preset

Then
Regex script = enabled
```

После смены пресета регекс получит обратное состояние.

Это удобно для:

- тогглов
- чекбоксов
- регексов
- Quick Reply sets

## Управление линками

В списке линков доступны быстрые действия:

- включить или выключить линк
- вручную запустить `Then`
- дублировать
- удалить

Дублирование удобно для похожих правил под разные пресеты, модели или карточки.

## Импорт и экспорт

Линки можно выгружать в JSON и загружать обратно.

Это подходит для:

- резервных копий
- переноса между профилями
- обмена готовыми наборами правил

## Как удобнее собирать линки

- называйте линк по его смыслу, например `Gemini preset and regex`
- держите один линк вокруг одной связки поведения
- используйте несколько `Then`, когда один триггер должен собрать весь нужный набор
- запускайте `Then` вручную, чтобы быстро проверить, что правило делает именно то, что нужно
